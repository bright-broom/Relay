# Relay サイドナビゲーション

2026-09-13

アプリ共通の移動と機能の入口は左サイドバーに集約する。日々の営業で使う優先順として、今日の対応 → 案件 → 料金シミュレーション → 日程調整 → 更新案 → 取込を配置する。その下に余白で区切って、マイページ → 管理者（権限がある人のみ）→ 情報を置く。言語設定のアイコンもサイドバー下部へ配置。上部にはプレビュー状態だけを表示する。

案件一覧の顧客リンク、詳細から一覧への戻る、更新案から対象案件を開く等は、内容に紐付く操作としてその場所に置く。トップページに重複していた取込ショートカットは除去した。

## 境界

- `src/prototype/navigation.ts` がメニュー定義とページ解決の正本。ページリンクとダイアログ起動を判別可能な型で分離。
- ページは通常のアンカーで遷移し、ブラウザーの戻る・進むを保つ。機能ダイアログはボタンで開く。ダイアログを未実装のURLへ見せかけない。
- `aria-current` はページの現在地に使用。案件詳細でも「案件」を現在地にする。開いている機能は `aria-expanded` と見た目で表示。
- 誤った案件IDは案件一覧へ戻し、別の顧客を代わりに開かない。削除済みの `#system` 等は今日の対応へフォールバック。`#main` はスキップリンクとして描画し直さない。

## レイアウトと操作

PC・スマートフォンとも左側のアイコンレールを維持。スマートフォン幅は中央トークンで68px、ノッチの安全領域を加算する。右側の業務画面は既存の一列レイアウトへ切り替わる。

サイドバー自体が縦スクロールでき、横向き・低いウィンドウでも末尾の操作へ到達できる。スクロール位置はページ再描画で引き継ぐ。廃止した上部展開メニューの状態・開閉処理・専用CSSを削除した。

アイコンは翻訳済みの読み上げ名と標準ツールチップを持つ。Tabで通常のリンク・ボタン・言語設定へ移動できる。選択ページには面と線を付ける。モーダルのフォーカス制御は共通のshadcn/ui Dialogを使用し、閉じると起動ボタンへ戻す。アプリ内の追加ボタン・追加案内・インストールイベント処理は削除済み。既存のホーム画面アプリ向けmanifestと旧キャッシュ廃止処理は維持する。

## マイページ

`#mypage` は独立した個人設定ページ。Googleでログインしている本人のメールアドレス・権限・ログアウトと、表示言語を配置する。認証・アクセス許可のサーバー側の境界は維持する。独立したアカウント連携ページ・ダイアログは設けない。

LINE通知の設定はマイページ内の折りたたみに統合する。初回に開くまで通知先を取得せず、一度開いた後は閉じても選択と連携コードを保持する。通知設定の読み込み失敗はプロフィール表示やログアウトを妨げない。カレンダー接続は日程調整の文脈に残す。

## 確認範囲

`npm run check`で型・翻訳・CSS参照・計算・認証等を確認する。ナビゲーションでは、リンクとルートの整合、不正案件ID、現在地、スキップリンク、優先順、管理者項目の表示条件、廃止した連携・追加メニューの不在を検証する。

ブラウザーのURL安全ポリシーでローカル画面へのアクセスが拒否されているため、390 / 768 / 1440pxでの実表示とキーボード操作は未検証。レイアウト実装と自動検証を、実画面での確認済みとは扱わない。
