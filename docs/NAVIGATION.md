# Relay サイドナビゲーション

2026-09-13

アプリ共通の移動と機能の入口は左サイドバーに集約する。今日の対応・案件・更新案・取込に加え、料金シミュレーション・日程調整・アカウント・インストール・情報を配置する。言語設定のアイコンもサイドバー下部へ配置。上部にはプレビュー状態だけを表示する。

案件一覧の顧客リンク、詳細から一覧への戻る、更新案から対象案件を開く等は、内容に紐付く操作としてその場所に置く。トップページに重複していた取込ショートカットは除去した。

## 境界

- `src/prototype/navigation.ts` がメニュー定義とページ解決の正本。ページリンクとダイアログ起動を判別可能な型で分離。
- ページは通常のアンカーで遷移し、ブラウザーの戻る・進むを保つ。機能ダイアログはボタンで開く。ダイアログを未実装のURLへ見せかけない。
- `aria-current` はページの現在地に使用。案件詳細でも「案件」を現在地にする。開いている機能は `aria-expanded` と見た目で表示。
- 誤った案件IDは案件一覧へ戻し、別の顧客を代わりに開かない。削除済みの `#system` 等は今日の対応へフォールバック。`#main` はスキップリンクとして描画し直さない。

## レイアウトと操作

PC・スマートフォンとも左側のアイコンレールを維持。スマートフォン幅は中央トークンで68px、ノッチの安全領域を加算する。右側の業務画面は既存の一列レイアウトへ切り替わる。

サイドバー自体が縦スクロールでき、横向き・低いウィンドウでも末尾の操作へ到達できる。スクロール位置はページ再描画で引き継ぐ。廃止した上部展開メニューの状態・開閉処理・専用CSSを削除した。

アイコンは翻訳済みの読み上げ名と標準ツールチップを持つ。Tabで通常のリンク・ボタン・言語設定へ移動できる。選択ページには面と線を付ける。モーダルのフォーカス制御は既存のネイティブdialogを使用し、閉じると起動ボタンへ戻す。インストール済みのホーム画面アプリではインストール案内を隠す。

## 確認範囲

`npm run check`で型・翻訳・CSS参照・計算・認証等を確認する。ナビゲーションでは、リンクとルートの整合、不正案件ID、現在地、スキップリンク、インストール済みの場合の項目除外を検証する。

ブラウザーのURL安全ポリシーでローカル画面へのアクセスが拒否されているため、390 / 768 / 1440pxでの実表示とキーボード操作は未検証。レイアウト実装と自動検証を、実画面での確認済みとは扱わない。
