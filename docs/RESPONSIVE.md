# Relay レスポンシブ仕様

2026-09-13。スマートフォン、iPadの縦横・分割表示、PCの可変ウィンドウを同じReactツリーで扱う。端末判定による画面の複製・再マウントをせず、入力値とフォーカスを保持する。全機種の実動作確認済みという意味ではない。

## 幅とレイアウト

余白・サイドバーはウィンドウ幅、段組みはmain／dialog-bodyの**コンテンツ幅**で決める。段組みの境界は `src/design/tokens.ts` のbreakpointsが正本。CSSのコンテナークエリーは、サイドバー・余白を引いた実幅を参照する。本文・入力の16px、操作の44〜48px、3色は維持する。

| 対象 | 狭い領域 | 広い領域 |
|---|---|---|
| 今日 | 指標を縦配置、対応カードを折返し | 指標3列 |
| 案件一覧 | カード1列 | 36rem以上で2列、56rem以上で一覧表 |
| 案件詳細・報告 | 情報と報告を縦配置 | 64rem以上で情報＋報告の2列 |
| 更新案の確認 | 変更前後・選択・操作を縦配置 | 36rem以上で比較2列 |
| 情報取込 | 1列、結果と操作を折返し | 結果項目を2列 |
| 料金・日程 | 条件と比較を1列 | 36rem以上で2列 |
| アカウント・言語・引継ぎ・案内 | 幅内で折返し、必要時に本文をスクロール | 読み幅を制限 |
| Googleログイン | 自然に伸びる1列フォーム | 中央の読み幅に制限 |

事実項目と検索条件は30rem以上で2列。コンテナークエリーの非対応環境では、フォーム・詳細・案件カードの1列を基本とする。基礎余白の境界は30 / 48 / 64rem。端末の機種名や向きには依存しない。

## スクロールと操作

- 全幅でサイドメニューを維持する。スクロール高さ未指定のappにoverflowを付けず、ページを下へ送ってもstickyが働く構造に修正。低い画面ではサイドバー自体をスクロールできる。
- 幅30rem以下または高さ32rem以下では共通Dialogを全画面にする。料金提示も全画面。通常のダイアログは最大44rem。
- Dialogの見出しと閉じるボタンを、スクロールする本文から分離する。本文だけ縮小・スクロールし、閉じるボタンが本文に埋もれないようにする。AlertDialogも表示中の画面高さ・位置へ追従する。
- VisualViewportの高さ・位置でキーボード表示と回転に追従。フォーカス中の入力がDialog本文からはみ出す場合は、その本文だけを必要量スクロールする。背景ページへスクロール命令を送らず、フォーカスも移さない。
- ピンチ拡大中はVisualViewportによる高さの上書きを解除し、拡大に合わせてUIを縮めない。ズーム禁止のviewport指定は追加しない。
- ノッチ・ホームインジケーターの安全領域を適用。RTLでは論理方向の安全領域を入れ替え、時系列の線と余白も同じ方向へそろえる。
- 金額表示を「今日」の指標行用の横並びルールから分離。長い業務文字列・翻訳・キーの折返しとGrid/Flexの最小幅を整える。金額計算と確認ゲートは変更しない。
- トーストもキーボード上の可視領域へ配置し、長い通知は領域内でスクロールする。

## 検証の範囲

`npm run check` に `test:viewport` を追加。キーボード縮小・連続リサイズ・上下の入力遮蔽・ピンチ拡大と復帰・API非対応・イベント解除を、合成デバイスイベントと矩形で検証する。CSS解析でstickyを妨げる祖先スクロールの再導入、Dialogのスクロール境界も確認。既存のReact操作、入力保持、計算、認証・連携テストを併用する。

**これらは実ブラウザーのレイアウト／タッチ検証ではない。** 既存のブラウザーURL安全確認がローカル画面へのアクセスを拒否しているため、別URLや別ツールで迂回しない。以下は実表示での受入確認が必要な対象であり、確認済み一覧ではない。

| 確認対象 | 幅・条件 |
|---|---|
| 小型スマホ〜大型スマホ | 320 / 375 / 390 / 430px、縦横 |
| iPad・Androidタブレット | 768 / 820 / 1024px、縦横 |
| iPad分割表示 | 375 / 507 / 683px相当 |
| PC・大型画面 | 1280 / 1440 / 1920px |
| 拡大・文字 | 200%ズーム、長い英語・日本語、RTL |
| 操作 | メニュー最下段、全ページ、全Dialog、提示モード、閉じる、入力中の回転・キーボード、Tab・Escape・フォーカス復帰 |
| 状態 | 0件・保存失敗・通信失敗・長い金額・未確認の料金・未接続アカウント |

表示時には、ページ全体の横はみ出し、重なり、フォーカスの遮蔽、操作の到達可能性、入力保持を確認する。実Google／LINE送受信や実DB接続の確認とは分けて記録する。

参照：[MDN コンテナークエリーの幅指定](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/container-type)、[MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)。依存ライブラリの追加・更新は行っていない。
