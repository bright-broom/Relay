# Relay 国際化・操作部品

2026-09-13

## 文言と画面の境界

- `src/i18n/locales/ja.ts` / `en.ts`：表示文言・読み上げ名・入力エラー・通知・引き継ぎ文の正本。日本語キー型と英語のキー型を一致させる。
- `src/i18n/messages.ts`：i18next設定、翻訳リソース登録、BCP 47言語タグの検証、英語へのフォールバック。従来の `translate` はこの層への互換入口。
- `src/i18n/context.ts`：`UiContext` を生成し、`t`・数値・整数円の通貨表示・日付・日時範囲・入力数字の正規化を提供する。
- 主要5ページ、料金、日程、アカウント、言語設定は共通コンテキストを受け取る。ログイン画面も同じコンテキストと文言を使う。各画面で独自の言語選択や翻訳テーブルを定義しない。
- 案件名・会話・履歴などの業務データは翻訳リソースへ混ぜず原文を維持する。既存の承認サンプルは原文の日本語を記録する。UI言語を切り替えて既存の記録を書き換えない。

## 言語の対応範囲

翻訳済みの画面は日本語と英語。BCP 47の有効な言語タグを指定でき、地域付き言語は基底言語のリソースへ解決する。未翻訳は英語で表示し、その状態を明示する。これは全世界の言語を翻訳済みという意味ではない。Intlの書式データは利用ブラウザーの対応範囲に依存する。

サイドバーの言語アイコンから候補を選ぶか、任意の言語タグを入力する。端末保存とHTTPSの設定用Cookieへ保存し、ログイン画面にも引き継ぐ。Cookieに認証情報や業務データは入れない。ログイン画面のフォームはJavaScriptが使えない場合もGETで言語を指定できる。

翻訳言語と書式言語を分離する。たとえば `ar-EG` を指定した場合、画面文言は未翻訳のため英語、金額・日時とレイアウト方向はアラビア語の設定となる。HTMLの `lang` は実際の文言の言語、`dir` は選択された方向を表す。左右の矢印と選択状態の線もRTLへ対応する。

新しい翻訳は `locales/<tag>.ts` を作成し、既存キーとの型一致・変数一致・複数形を確認して `catalogs` へ登録する。現在のLINEテスト通知は既存DBの対応言語（日本語・英語）へ解決して送る。通知の翻訳言語そのものを追加する場合はDBのlocale制約の移行も必要。

i18nextの共有インスタンスの現在言語はリクエストごとに変更しない。翻訳時にlocaleを指定し、並行リクエストで別ユーザーの言語が混入しない構成とする。初期リソースは同梱し、外部翻訳サービスへの送信や実行時の辞書取得は行わない。

## アイコンと認知負荷

`src/ui/icons.ts` にLucideアイコンと操作の意味を集約。必要なアイコンだけを名前付きで取り込む。画面ごとのSVGの複製を廃止し、線幅・色・サイズは既存トークンに接続する。

コピー・更新・ログアウト・切断・編集・移動などはアイコン化し、翻訳済みの読み上げ名とツールチップを持つ。案件の状態は形が異なるアイコンで表す。件数指標には意味を誤認しない短いラベルを残す。

承認、完了保存、予定登録、通知送信、料金提示などの判断・外部作用がある操作は、アイコンに短い動詞を添える。金額、期限、費用の範囲、未確認事項、入力エラーはアイコンへ置き換えない。取込画面では選択肢が一つしかないプルダウンを削除し、サンプルであることと結果を簡潔に示す。

## 金額と日付

比較計算は既存の整数JPYモデルを維持する。金額表示はBigIntからIntlへ渡し、Numberへ変換して精度を失わない。アラビア数字・ペルシャ数字・全角数字等は画面の入力境界でASCIIへ正規化してから既存スキーマに渡す。小数・負数・桁区切りの扱いを勝手に変更しない。

人が読む日付はコンテキストの書式を使用し、APIやdate入力に使うISO日付は別ヘルパーで生成する。選択言語によってAPI入力の数字・日付形式を変更しない。

## 検証と未確認事項

`npm run check` にi18nテストを追加。全辞書のキーと変数、英語の単数・複数、地域言語とフォールバック、RTL、正確な金額、地域数字の入力、サーバーHTMLへの不正値混入防止、言語コンテキストの分離、重要操作の可視ラベルを検証する。ページの日本語直書きと文言・CSSの未参照監査も実行する。

ブラウザーのURL安全ポリシーがローカル画面へのアクセスを拒否しているため、実画面での390 / 768 / 1440px・RTL・キーボード・スクリーンリーダー検証は未完了。コードと自動テストを、実機での確認済みと混同しない。

参照：[i18next API](https://www.i18next.com/overview/api)、[フォールバック](https://www.i18next.com/principles/fallback)、[Lucide](https://lucide.dev/guide/lucide)。採用版はi18next 26.4.2、Lucide 1.45.0。
