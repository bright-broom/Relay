# ADR 0001：顧客台帳を独立した権限で段階導入する

2026-09-17 / ローカル実装に採用。本番適用は未承認・未実施。

既存の Google 認証用接続は CRM の所属権限を表現しないため、顧客を同じ権限で保存すると RLS を迂回する構成になり得る。

CRM_DATABASE_URL と専用の制限された実行ロールを設ける。本人・所属を事前登録し、最初の実装は顧客登録・一覧・再取得に限定する。SECURITY DEFINER を使わない RLS、権限行のロック、監査と再送の同一トランザクションを採用する。既存の画面・認証・LINE・カレンダーを置き換えない。

接続を分ける運用負荷を受け入れ、未設定時は顧客機能を閉じる。所属内共有は既存設計に従い、実データ導入前に運用責任者が確認する。更新・アーカイブ・他の業務テーブルは後続の変更とする。

権限・API・検証・撤退の詳細は [CRM_IMPLEMENTATION.md](../CRM_IMPLEMENTATION.md) を正本とする。
